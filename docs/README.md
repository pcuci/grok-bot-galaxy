## Reading evidence

A source recording establishes what is audible, not whether a narrated action
actually succeeded elsewhere. ASR is fallible and has no speaker diarization.
Edited transcripts must retain ambiguity. Synthesis follows reviewed chapters,
not the other way around. See the Day 1 [review queue](days/day-01/review-queue.md)
for unresolved gates and editorial issues.
